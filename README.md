# Shopingmall_management


A console-based **Shopping Mall Management System** developed using **Core Java**. This project allows users to select products, enter quantities, and automatically calculate the total bill.

## 🚀 Features

* 🛒 Product selection
* 📦 Quantity management
* 💰 Automatic bill calculation
* 🧾 Total bill generation
* ⌨️ Simple console-based interface
* 🔄 Menu-driven program

## 🛠️ Technologies Used

* **Java**
* **Core Java**
* **Scanner**
* **Loops**
* **Conditional Statements**

## 📋 Products

The project includes products such as:

* 👕 Shirt
* 👖 Jeans
* 👟 Shoes

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project in **IntelliJ IDEA** or any Java IDE.
3. Open the main Java file.
4. Compile and run the program.
5. Follow the instructions displayed in the console.
